# M3 検証記録 — ローカル戦闘（2026-10-31）

## 受け入れ基準と結果

| 項目 | 基準 | 結果 |
|---|---|---|
| GPU HitTest | レイ×512スロット、壁遮蔽込み | ✅ 8レイ全弾命中（dist=7.10=胸高さ、slot特定）、壁距離はCPUのPhysics.Raycastで事前クリップ |
| ローカル戦闘 | ヒット→ダメージ→死亡→キル要求 | ✅ 5バレット（40レイ×12dmg）で11キル、キル要求バッチ化（n=1〜3/バッチ） |
| フレームスパイク | フルオート＋ペレットでスパイクなし | ✅ 戦闘中のUdon SimStep平均 **0.105〜0.111ms**（予算0.5ms） |
| ヒットフィードバック | 即時 | ✅ 被弾フラッシュ（State.w）＋よろけ（Stagger）はシム内で即時発現 |

## 実装の要点

- **HitTestパス**（EnemySim.compeito）: 出力8×1 RT（各テクセル=レイごとの最良命中 dist+slot）。判定球は**胸高さ(y+0.9)・半径0.45**（シム位置は足元のため、足元中心だと床終端レイや胸高さ射撃が全て外れるバグを修正）。
- **レイ経路**: GunControllerがペレットごとに`Physics.Raycast`（壁=Environmentレイヤー）→`hordeSim.QueueRay`（最大8/フレーム）→シムフレームのHitTest Dispatch→**非同期readback 32B/射撃**→`hitRayDist/hitRaySlot`配列＋`hitBatchId`インクリメント→リスナー（Gun）に`_OnHitResults`。
- **戦闘同期の原則の実装**: ヒット毎のネットワークイベントは**存在しない**。ローカル即時ダメージ適用（QueueDamage→cmdテクスチャ）、死亡はミラー監視で検出→キル要求をバッファ→0.2sバッチ（M4でNetworkCallable化）。
- **readbackウォッチドッグ**: 非同期readbackコールバックがエラーなしで沈黙するケース（エディタで確認）に対し、0.5sタイムアウトでフラグを再アーム。pos→state→hitのチェーン継続性を保証。

## 検証上の注意

- ミラーはpos/stateで読み取り時点が僅かにずれる（チェーン＋ウォッチドッグの代償）。監査系は数秒置いて実施。GPU HitTest・レンダーはRT直接読みのため常に新鮮。
- デバッグ射撃（`_DebugTestShots`）はアリーナ中央上空(0,8,0)から下向き8レイ。群衆がプレイヤー位置に収束している前提。
